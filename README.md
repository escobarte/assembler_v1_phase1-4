# AI-Ready Starter Kit: Premium Minimalism

## Как применить:

1. Git Clone
2. Настроить токены в cc_design/DESIGN.md
3. Начать верстку через ИИ-агента.
This is 1st Version «AI-Ready Starter Kit».
Это не просто проект, а настроенная среда, где ИИ уже знает, как кодить в премиальном минималистичном стиле (Swiss Design / Framer aesthetics).

🚀 Next.js + Tailwind AI-Driven Template
Этот репозиторий — готовый фундамент для быстрой разработки веб-интерфейсов. Главная фишка: проект полностью оптимизирован для работы с Claude Code, настроен на обход дефолтных стилей shadcn и содержит «обученных» субагентов.

🛠 Стек технологий
Framework: Next.js 14 (App Router, Server Components)

Styling: Tailwind CSS + shadcn/ui + Custom Design Tokens

Animations: Framer Motion

Language: TypeScript

AI Tooling: Claude Code (с настроенными агентами и скиллами)

📦 Что внутри (Core Features)
Design System: Система переопределения скучных дефолтов в tailwind.config.ts и globals.css на основе папки cc_design.

AI Agents: Ваш личный Senior Frontend (Claude), который подчиняется строгим правилам из CLAUDE.md.

Workflow: Файл Instructions.md с описанием 5 фаз разработки для контроля галлюцинаций ИИ.

🚀 Как запустить
Клонируйте репозиторий.

Установите зависимости:

Bash
npm install
Запустите Claude Code в корне папки:

Bash
claude
Делегируйте задачи:
@ui-react-tailwind-specialist Создай новую секцию Hero на основе гайдлайнов DESIGN.md и скриншота...

📂 Структура для переиспользования
src/components/ui/ — библиотека базовых компонентов shadcn.

CLAUDE.md — глобальные правила поведения (сетка, архитектура, запреты).

cc_design/DESIGN.md — документация визуального стиля (шрифты, отступы, палитра).

Instructions.md — пошаговый алгоритм работы с ИИ.

🗺 Краткий алгоритм (5 Фаз)
Чтобы сайт получился качественным, работа ИИ разбита на фазы:

Фаза 1 & 2 (Скелет): Настройка проекта и глобального Layout по сетке.

Фаза 3 (Мышцы): Импорт UI-компонентов и переопределение их стилей под DESIGN.md.

Фаза 4 (Кожа): Пошаговая верстка секций по скриншотам-референсам с добавлением анимаций.

Фаза 5 (QA): Финальный аудит отступов, "воздуха" и контрастности.

Зачем это хранить? Чтобы не настраивать конфиги и не объяснять Клоду правила скруглений, теней и Vercel Best Practices каждый раз с нуля. Просто развернул — и сразу пилишь.
